# Jetalon GT6 Diagnostic v1

A read-only/safe launcher utility for the Jetalon GT6 Android head unit.

Buttons attempt to open Android's built-in Developer Options, Wireless Debugging, Android Settings, Device Info, and USB settings. The app does not root, flash firmware, enable ADB by itself, or write hidden system settings.

## Codemagic
Upload the contents of this folder to a GitHub repository and start the `Jetalon Diagnostic v1 APK` workflow. Download `app-debug.apk` from artifacts and install it on the Jetalon.

## First test
1. Tap **Developer Options**.
2. If it opens, photograph the screen before changing anything.
3. If it fails, tap **Wireless Debugging** and photograph/copy the diagnostic log.
